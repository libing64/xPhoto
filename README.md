# xPhoto — RAW 自动修图工具

把一整个目录的 RAW 文件（索尼 `.ARW`，也支持 `.DNG / .CR2 / .CR3 / .NEF / .RAF …`）
自动修完：**解码 → 场景分析 → 调色 → 降噪 → 导出**，再用一个网页把效果看得见、调得动。

```
data/*.ARW  ──xphoto.py──▶  out/*.jpg + out/manifest.json  ──index.html──▶  浏览器里的编辑器
```

## 快速开始

```bash
# 1) 依赖（只需一次）
python3 -m venv .venv && .venv/bin/pip install rawpy numpy scipy pillow

# 2) 修图：读取 data/，输出到 out/
.venv/bin/python xphoto.py --input data --output out

# 3) 起一个本地服务（浏览器不允许 file:// 直接读 out/manifest.json）
python3 -m http.server 8080

# 4) 打开 http://localhost:8080
```

12 张 10MP 的 ARW 在 4 核并行下约 26 秒处理完。

## 目录

| 路径 | 说明 |
| --- | --- |
| `xphoto.py` | 修图流水线（CLI） |
| `index.html` / `app.js` / `styles.css` | 网页端：相册 + 编辑器（WebGL 实时渲染） |
| `data/` | 原始 RAW（不入库） |
| `out/` | 生成的素材：`<id>/neutral.jpg`（平灰底片）、`auto.jpg`（自动修图）、`full.jpg`（全分辨率）、`thumb.jpg`，以及 `manifest.json` |

## 流水线做了什么

1. **解码**：LibRaw 按相机白平衡 + sRGB 矩阵 + AHD 去马赛克，输出线性 16bit。
2. **归一**：黑/白点归一，把 99.5 分位压到 0.9，得到一张"平灰"的中性底片（`neutral.jpg`，也就是网页里的"原片"）。
3. **场景分析**：亮度分位（1/5/10/25/50/75/90/98/99.5）、过曝比例、色度饱和度均值、肤色像素占比（按色相 8°–46° 判定）、噪声 σ（高通残差的 MAD 估计）。
4. **自动调色**：曝光（中位亮度死区 0.36–0.52）、灰世界白平衡微调（限 ±8，防止毁掉日落/暖灯）、阴影提亮、高光回收、S 曲线对比、中间调钟形提亮、肤色保护的鲜艳度。
5. **降噪**：亮度/色度分离的**引导滤波**。亮度用 σ 自适应的 eps 做边缘保持平滑，色度用大半径强平滑（人眼对色度噪声更宽容）。强度由 ISO 与 σ 共同决定。
6. **细节**：双尺度局部对比（小半径=质感，大半径=去灰），非锐化掩膜锐化（带光晕钳制）。
7. **导出**：`neutral / auto / full / thumb` 四套 JPEG + `manifest.json`（含 EXIF、分析数据、三套风格参数）。

三套风格参数（自然 / 通透 / 胶片）在 Python 端算好后写进 manifest，网页端用**同一套数学公式**在 GPU 上重算，所以：

> 网页默认看到的效果 ≈ 导出的 `auto.jpg`，滑块只是在这套公式上继续微调。

## 网页端操作

| 操作 | 说明 |
| --- | --- |
| 点击照片 | 进入编辑器 |
| 拖动画面中的竖分割线 | 左边原片 / 右边修图，实时对比 |
| 按住「对比」或空格 | 整幅切换成 RAW 原片 |
| 滚轮 / 双击 / 0 | 缩放，双击或 `0` 复位 |
| 拖动画面 | 放大后可平移 |
| 右侧滑块 | 曝光、对比、高光、阴影、中间调、色温、色调、饱和度、鲜艳度、清晰度、降噪、锐化 |
| 预设 | 自然 / 通透 / 胶片，一键切换（改过参数会自动取消高亮） |
| `←` `→` | 上一张 / 下一张；`Esc` 返回相册 |
| 导出 | 按当前参数在浏览器里重渲染并下载 JPEG；也可下载 Python 导出的全分辨率版本 |

深链：`index.html#DSC07910/vivid` 直接打开某张图的某个预设。

## 常用参数

```bash
python xphoto.py --input data --output out \
  --preview 2200     # 网页预览长边（默认 2200，兼顾清晰度与显存）
  --thumb 560        # 相册缩略图
  --jobs 4           # 并行进程数（每张峰值约 1GB 内存）
  --limit 3          # 只处理前 3 张，调试用
```

## 说明与取舍

- **白平衡只做微调**：这是幼儿园/水族馆这类生活照，灰世界全量校正会把暖光、夕阳、霓虹全部拉平，所以限制在 ±8 内，剩下的交给色温滑块。
- **肤色保护**：检测到肤色占比高时，自动降低鲜艳度与清晰度，避免脸变"塑料"或"脏"。
- **网页的降噪是近似**：GPU 端用 9 taps 的双边近似替代 CPU 的引导滤波，预览效果接近但不是逐像素相同；追求最终画质请用 `out/<id>/full.jpg`。
- 输出 JPEG 是 sRGB / 8bit。需要 16bit TIFF 或更严格的色彩管理，可以改 `save_jpeg` 换成 `tifffile`。
