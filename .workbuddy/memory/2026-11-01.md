# 2026-11-01

## xPhoto：RAW 自动修图工具（从零搭建）

**目标**：读取 `data/*.ARW`（12 张 SONY ILCE-7M3 10MP），自动调色 + 去噪，导出结果并在网页里可视化调参。

**产出**
- `xphoto.py`：rawpy 解码 → 白点归一 → 场景统计 → 自动参数 → 引导滤波降噪 → 色调链 → 导出 `out/<id>/{neutral,auto,full,thumb}.jpg` + `manifest.json`
- `index.html` / `app.js` / `styles.css`：相册 + WebGL 编辑器（前后分割对比、12 滑块、3 预设、缩放平移、导出）
- `README.md`：用法与算法说明

**关键技术点（可复用）**
- 环境无 exiftool/dcraw，EXIF 自己解析 TIFF IFD（`_read_ifd`），ARW 的 ExifIFD 在 IFD0 里也能取到相机/镜头/ISO。
- rawpy `postprocess(use_camera_wb=True, no_auto_bright=True, gamma=(1,1), output_bps=16)` 拿线性数据，1.0≈传感器饱和；再用 p99.5→0.9 归一。
- 降噪：亮度引导滤波（eps 随 σ）+ 色度大半径引导滤波；σ 用高通残差 MAD 估。
- **内存坑**：本沙箱 RLIMIT_AS = 4GB/进程。numpy 里 `0.6 * bool_mask` 会升 float64 导致 10MP 图多耗 250MB，务必 `.astype(np.float32)`。
- multiprocessing + rawpy(OpenMP) 必须用 `spawn`，否则 fork 警告/死锁。
- 两端公式一致性验证：把 GLSL 逐行移植到 numpy 对比 Python render，平均误差 0.2%（`/tmp/glslsim.py` 思路可复用）。

**网页端注意**
- headless chrome 截图在本机被安全策略拦截（core dump），改用"GLSL→numpy 对拍 + 人工 code review"验证。
- `requestRender` 里 `state.dirty` 初值必须是 false，否则首帧被跳过（踩过）。
