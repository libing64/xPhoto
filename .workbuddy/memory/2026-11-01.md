# 2026-11-01

## xPhoto：RAW 自动修图工具（从零搭建）

**目标**：读取 `data/*.ARW`（12 张 SONY ILCE-7M3 10MP），自动调色 + 去噪，导出结果并在网页里可视化调参。

**产出**
- `xphoto.py`：rawpy 解码 → 白点归一 → 场景统计 → 自动参数 → 引导滤波降噪 → 色调链 → 导出 `out/<id>/{neutral,auto,full,thumb}.jpg` + `manifest.json`
- `index.html` / `app.js` / `styles.css`：相册 + WebGL 编辑器（前后分割对比、12 滑块、3 预设、缩放平移、导出）
- `README.md`：用法与算法说明

**关键技术点（可复用）**
- 环境无 exiftool/dcraw，EXIF 自己解析 TIFF IFD（`_read_ifd`），ARW 的 ExifIFD 在 IFD0 里也能取到相机/镜头/ISO。
- rawpy `postprocess(use_camera_wb=True, no_auto_bright=True, gamma=(1,1), output_bps=16)` 拿线性数据，1.0≈传感器饱和；再用 p99.5→0.9 归一。
- 降噪：亮度引导滤波（eps 随 σ）+ 色度大半径引导滤波；σ 用高通残差 MAD 估。
- **内存坑**：本沙箱 RLIMIT_AS = 4GB/进程。numpy 里 `0.6 * bool_mask` 会升 float64 导致 10MP 图多耗 250MB，务必 `.astype(np.float32)`。
- multiprocessing + rawpy(OpenMP) 必须用 `spawn`，否则 fork 警告/死锁。
- 两端公式一致性验证：把 GLSL 逐行移植到 numpy 对比 Python render，平均误差 0.2%（`/tmp/glslsim.py` 思路可复用）。

**网页端注意**
- headless chrome 截图在本机被安全策略拦截（core dump），改用"GLSL→numpy 对拍 + 人工 code review"验证。
- `requestRender` 里 `state.dirty` 初值必须是 false，否则首帧被跳过（踩过）。

## 第二轮：引入 darktable

**做法（本机无 darktable，无法真跑）**
- `--engine auto|native|darktable` + `--darktable PATH` + `--dt-style NAME`；`find_darktable()` 按 显式参数→env `DARKTABLE_CLI`→PATH→常见路径 查找。
- darktable 只当"显影前端"：`darktable-cli <raw> <jpg> --core --hq true --bpp 8 [--width/--height] [--style]`，产出 `dt_base.jpg`，之后仍走自家分析+调色。
- **不写 XMP**：darktable 历史记录里模块参数是二进制结构体（含 modversion），手写极易黑图；这是本项目的明确设计决定。
- 用 mock `darktable-cli`（rawpy 写 JPEG）验证了整条外部引擎链路：查找→subprocess→读回→manifest engine 字段→降噪强度自动降到 35%。

**原生引擎升级（darktable 级算法）**
- 降噪：à trous B3 样条三层软阈值（`_atrous_blur` + `SCALE_SIGMA=(0.852,0.446,0.233)`，色度阈值×2.4），10MP 1.17s，比原引导滤波快 3 倍。
- 高光肩部：扩展 Reinhard `L(1+L/W²)/(1+L)`，W 来自 `analysis.whiteLin`（p99.9 线性）。
- 色彩分级：新参数 `shadowTint`/`highlightTint`（color balance rgb 思路），通透预设走青橙、胶片预设暖阴影冷高光。
- 两端一致性复测：关掉降噪后 GLSL vs numpy 平均误差 0.23%；开着降噪 1.1%（差异全来自 CPU 小波 vs GPU 双边）。

**环境坑**
- `apt-get download` + `dpkg -x` 能拿到 darktable 4.6.1 的 deb（只缺 libavif/libGraphicsMagick/libpugixml/libcolord-gtk 四个库），但解包与运行命令被安全策略拦下，未继续。
- data/ 目录后来增加到 21 张图（用户新增），全量处理 48s。
